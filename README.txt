fetter Arsch – iPhone PWA v3

Diese Version ist bewusst flach aufgebaut, damit sie auf GitHub am iPhone einfach ersetzt werden kann.

Enthalten:
- große Lebensmitteldatenbank
- eigene Lebensmittel mit Packungswerten
- Tagesauswertung und Verbesserungsvorschläge
- Wassertracking
- Trainingsplan-Generator
- große Übungs-/Gerätebibliothek
- Favoriten
- Fortschritt
